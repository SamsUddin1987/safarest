SAFAR EDGE — SPLIT MODE / PER-PROJECT SETTINGS

Baseline: mysite(20261126-032524).zip

Changed files:
- home/templates/cad_workspace.html
- home/static/js/cad/interaction/cad-snapping.js
- home/static/js/cad/interaction/cad-split-view.js
- home/static/js/cad/io/cad-project-files.js

Changes:
1. Status-bar control is labelled "Split ◧".
2. When Split is ON, both CAD and Spreadsheet stay visible. The CAD and
   Spreadsheet tab buttons are disabled, and switchAppTab() blocks tab changes.
3. The split enabled state and divider ratio are embedded in each .est project.
4. A stable project ID is stored in the .est file. Browser fallback settings are
   keyed by project ID and filename, so different projects with different IDs
   keep separate layouts.
5. Opening a project restores its own split state and divider ratio.
6. Changing Split state or divider position marks the project dirty and invokes
   the existing AutoSave / recovery workflow.
7. Legacy .est files without a project ID use their filename as a fallback.
   The ID becomes part of the file when the project is next saved.

Install:
- Back up the project.
- Extract this ZIP into the Django project root, preserving folders.
- Overwrite the listed existing files and add cad-split-view.js if absent.
- Hard-refresh the website (Ctrl+Shift+R).

Persistence note:
- In browsers that grant write access to the selected .est file, the workspace
  setting is included in AutoSave and travels with that project file.
- Firefox does not support the same silent overwrite workflow. There, the
  browser-local project-ID / filename fallback and existing recovery snapshot
  restore the layout on that browser, including after hard refresh. To carry the
  setting inside the .est file to another browser/device, use Save / Save As
  after changing the split layout.
- Browser interaction testing has not been performed in this environment.
